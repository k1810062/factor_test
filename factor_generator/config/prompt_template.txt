## 任务

根据用户提供的研报或想法，提取所有因子。输出 JSON 格式：

```json
{
  "factors": [
    {
      "name": "因子英文名（蛇形命名）",
      "label": "因子中文名",
      "category": "分类（pv/fund/ind/monthly）",
      "domain": "domain（见下方规则）",
      "dsl": "纯表达式公式",
      "logic_summary": "因子逻辑简述"
    }
  ]
}
```

## domain 规则

domain 由**数据本身的频率**决定，不是计算窗口长度（如"20日"等参数）：

- DSL 公式默认操作日频数据 → stock（最常用）
- 行业日频 → industry
- 只有研报明确说"月度数据""月末截面"才用 stock_monthly / industry_monthly
- 不确定时默认 stock

即使公式中窗口参数为 20 日或 30 日，只要引用的是 stock_daily 的字段（CLOSE/VOLUME 等），domain 就为 stock。

## 命名规则

- name 用蛇形命名，如 ret_5d、mom_12m。优先用研报中已有的英文名
- 研报无英文名则按含义简洁缩写
- 不要重复加已有同义因子（通过 name 和 label 判断）

## 输出规则

只输出 DSL 公式，不输出 SELECT/JOIN/FROM 等 SQL 关键字。
字段名用大写: CLOSE, VOLUME, AMOUNT, HIGH, LOW, OPEN, MV, TURNOVER, PE, PB, ROE
可用算子（54 个）：ABS, LOG, SQRT, SIGN, POWER, SIGNEDPOWER, MAX, MIN, IF, DELAY, DELTA, MA, AVG, ADV, TS_MEAN, MEAN, STDDEV, SUM, TS_MAX, HHV, TS_MIN, LLV, RETURNS, CORRELATION, COVARIANCE, COUNT, EVERY, CROSS, RANK, ZSCORE, SCALE, EMA, SMA, WMA, TS_RANK, DECAY_LINEAR, SLOPE, FORCAST, BARSLAST, TS_ARGMAX, TS_ARGMIN, HHVBARS, LLVBARS, AVEDEV, EXIST, SUMIF, BARSLASTCOUNT, BARSSINCEN, LAST, VALUEWHEN, CONST, LONGCROSS, PRODUCT

```json
{
  "name": "mom_20d",
  "label": "20日动量",
  "category": "pv",
  "domain": "stock",
  "dsl": "RANK(CLOSE / DELAY(CLOSE, 20) - 1)",
  "logic_summary": "过去20日累计收益的横截面排名"
}
```

## 数据字段清单

- 字段名使用大写标准名（如 CLOSE、VOLUME）
- 禁止编造缩写或自定义字段名
- 不存在字段会由编译器标记异常，后续将反馈错误
