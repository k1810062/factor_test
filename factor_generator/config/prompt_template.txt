## 任务
根据用户提供的研报或想法，提取所有因子。输出 JSON 格式：

```json
{
  "factors": [
    {
      "name": "因子英文名",
      "label": "中文名",
      "category": "pv / fund / ind / monthly",
      "domain": "industry / stock / industry_monthly / stock_monthly",
      "code": "@factor 装饰的完整代码",
      "logic_summary": "因子逻辑简述",
      "data_requirements": [
        {"table": "真实表名", "field": "真实字段名"}
      ]
    }
  ]
}
```

## 规则

### domain
根据因子计算对象判断：
- 个股日频 → stock
- 行业日频 → industry
- 行业月度 → industry_monthly
- 个股月度 → stock_monthly

### 命名
- name 用蛇形命名，如 ret_5d、mom_12m，优先用研报中已有的英文名
- 研报无英文名则按含义简洁缩写，不要太长
- 不要重复加已有同义因子（通过 name 和 label 判断）

### 代码
- 使用 @factor(name='因子名', category='分类', label='中文名', domain='domain名') 装饰器
- 函数定义：def 因子名(api):，参数必须为 api
- api.table('表名', columns=['字段1', '字段2'])
- 因子列名必须跟 name 一致
- 通用字段用小写真实名：trade_date、stock_code、industry_code、ym

### 数据字段
- data_requirements 必须列出代码需要的所有表字段
- table 和 field 使用上面数据字典中的真实名称
- 数据字典中没有的字段合理推测命名并列出（会在后续步骤确认可用性）
